개발자 kavanutz는 로컬 LLM이 가중치를 수정하지 않고도 새로운 사실을 즉시 학습하고 오류를 수정할 수 있게 하는 Jayce라는 프레임워크를 공개했다. 핵심 메커니즘인 Adaptive Prototype Memory\(APM\)는 LLM의 원시 컨텍스트 벡터를 4,096개의 고정된 프로토타입 슬롯 풀에 저장하고, 모델이 틀린 답을 낼 때 정정을 받으면 가장 가까운 프로토타입 벡터를 새 데이터 쪽으로 즉시 이동시키는 방식으로 동작한다. 개발자는 이 방식이 Adam 옵티마이저 기반 표준 역전파보다 학습 업데이트 속도가 1.6배에서 4배 빠르고, MNIST 순차 테스트에서 동일한 학습 예제 수 기준 역전파보다 높은 정확도를 보였다고 주장한다. 전체 구현은 PyTorch나 TensorFlow 없이 순수 NumPy\(jayce\_tokens.py\)와 네이티브 Java\(JayceMemory.java\)로만 작성되었으며, 로컬 Qwen3-4B GGUF 모델과 함께 오프라인 소비자 하드웨어에서 완전히 동작하고, 벤치마크 데이터와 코드는 GitHub 저장소\(Loophole-LLC/Jayce\)에 공개되어 있다.

reddit · r/MachineLearning · /u/kavanutz · 9월 21일 19:44

**「배경 지식」** 로컬 LLM에 새로운 사실을 학습시키려면 기존에는 RAG 파이프라인을 구축하거나 모델 가중치를 직접 수정하는 파인튜닝을 해야 했는데, 파인튜닝은 시간이 오래 걸리고 기존에 학습된 지식을 잃어버리는 '재앙적 망각\(catastrophic forgetting\)' 문제를 일으킬 수 있다. 역전파\(backpropagation\)는 신경망 가중치를 오차에 따라 점진적으로 조정하는 표준 학습 방식으로, 대량의 예제와 반복 학습이 필요하다는 한계가 있다. 이번 프로젝트는 가중치 수정 대신 프로토타입 벡터 슬롯을 직접 이동시키는 방식으로 이러한 한계를 우회하려는 시도이다.

**「영향」** 이 접근이 실제로 검증된다면 로컬 LLM 사용자들은 무거운 RAG 파이프라인 구축이나 느리고 위험한 파인튜닝 없이도 모델에 새 사실을 빠르게 주입하고 재앙적 망각 문제를 완화할 수 있는 선택지를 얻게 된다. 다만 게시물 자체가 완전한 실험 검증 세부사항 없이 제안된 초기 프로토타입 형태이므로, 성능 주장과 확장성은 커뮤니티의 추가 검증이 필요하다.

**「배경」** Cloudflare는 서버리스 Workers 플랫폼에서 Python 코드를 실행할 수 있는 기능을 2년간 프리뷰로 운영해왔으며, 이번에 정식\(GA\) 지원으로 전환했다. Simon Willison은 이 발표를 소개하며, 특히 이 기능이 내부적으로 작동하는 방식에 주목한다.

**「방안」** 저자에 따르면 이 구현의 핵심은 Python 코드를 Pyodide를 통해 WebAssembly로 컴파일한 뒤, V8 기반의 workerd 런타임 안에서 실행한다는 점이다. 즉 Python이 네이티브로 돌아가는 것이 아니라 WASM VM 위에서 시뮬레이션되는 구조다. 이 방식은 표준 Python 생태계와의 호환성을 크게 넓혀주지만, Cloudflare 공식 문서가 밝히듯 multiprocessing과 threading은 WebAssembly VM의 한계로 인해 작동하지 않는다는 명확한 제약이 남아 있다. 저자는 로컬 개발 환경 구성도 흥미로운 디테일로 짚는다. pywrangler라는 CLI 도구\(PyPI에는 workers-py라는 다소 헷갈리는 이름으로 배포됨\)가 실제 프로덕션 스택 전체를 로컬에서 그대로 재현하는데, 여기에는 V8 안에서 WebAssembly로 Pyodide 코드를 실행하는 123MB 크기의 workerd 바이너리까지 포함된다. 저자의 환경에서는 이 바이너리가 node\_modules/@cloudflare/workerd-darwin-arm64/bin/workerd 경로에 설치되었다고 언급한다. 발표문에는 Gyeongjae Choi, Dominik Picheta, Hood Chatham이 크레딧으로 올라 있는데, 이 중 Gyeongjae와 Hood는 Pyodide 코어 메인테이너로, 저자는 이를 Cloudflare가 Python 생태계에 상당한 투자를 하고 있다는 신호로 해석한다.

**「결론」** 저자의 요지는, Cloudflare Python Workers가 WebAssembly 기반이라는 근본적 한계\(멀티프로세싱·스레딩 불가\)를 안은 채로도 실전 배포 가능한 수준의 정식 지원에 도달했으며, Pyodide 핵심 인력의 참여는 이것이 단순한 실험이 아니라 Python 생태계에 대한 진지한 장기 투자임을 보여준다는 것이다.
