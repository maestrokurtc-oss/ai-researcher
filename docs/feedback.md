# 독자 피드백

각 브리핑의 선정 콘텐츠와 **5.0점 이상 미선정 콘텐츠**에는 `좋아요`와
`별로예요` 버튼이 표시됩니다. 같은 버튼을 다시 누르면 선택이 취소되고,
반대 버튼을 누르면 반응이 변경됩니다.

## 기록하는 정보

- 보고서·콘텐츠 식별값, 노출 위치(선정/더 보기), AI 점수
- 콘텐츠 제목·URL·출처·프로필·태그
- 좋아요·별로예요·취소 이벤트와 기록 시각
- 중복 및 남용 완화를 위해 일방향 변환한 임의 브라우저 식별값

이름, 이메일, 원본 브라우저 식별값, 원본 IP는 저장하지 않습니다. IP에서
일방향 변환한 남용 제한 정보는 2시간 뒤 만료되고 후속 요청 때 삭제됩니다.

## 분석 원칙

반응 변경 이력을 잃지 않도록 모든 선택은 append-only 이벤트로 보관합니다.
현재 선호를 계산할 때는 같은 보고서·콘텐츠·브라우저 그룹에서 가장 최근
이벤트만 사용하고, 최근 이벤트가 `clear`인 그룹은 제외합니다.

공개 익명 반응은 자동화된 조작 가능성을 완전히 없앨 수 없는 참고 신호입니다.
따라서 기존 운영자 평가와 자동으로 합치지 않고, 일정 기간의 표본 수·출처·AI
점수와 함께 검토한 뒤 선별 기준 개선에 사용합니다.
